# Pasta Public

Coloque aqui os arquivos estaticos que voce quer disponibilizar no site:

- `public/images/`: Fotos do hotel, quartos, spa, natureza, etc.
- `public/videos/`: Videos promocionais, tour virtual, etc.

No codigo do React/Vite, eles podem ser acessados diretamente pela barra `/`:
- Exemplo de imagem: `<img src="/images/minha-foto.jpg" alt="..." />`
- Exemplo de video: `<video src="/videos/meu-video.mp4" controls />`
